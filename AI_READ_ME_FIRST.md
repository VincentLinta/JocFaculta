# AI: read this first

This Unity project (`jocfaculta`, Unity 6.6, URP) is a turn-based hide-and-seek horror game.

**All project knowledge lives in `Assets/ProjectMemory/`.** Read, in order:

1. `Assets/ProjectMemory/00_README.md` - what the game is, folder map
2. `Assets/ProjectMemory/09_WORKING_WITH_AI.md` - rules you must follow (never run Tools > Hide And Seek over the scene!)
3. `Assets/ProjectMemory/07_PROTECTED_AND_TESTED.md` - behavior that must keep working
4. The rest as needed (design, architecture, map, audio, tuning, changelog, known issues, scene snapshot)

Standing rule: at the end of every task, append an entry to `06_CHANGELOG.md`, update every doc that changed,
and refresh `10_SCENE_SNAPSHOT.md` with **Tools > Hide And Seek > Export Project Memory Snapshot**.
